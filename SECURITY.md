# Beveiligingsbeleid

## Ondersteunde versies

We voorzien de meest recente release van beveiligingsupdates. Oudere
releases krijgen alleen patches als de impact zwaarwegend is.

Releases volgen Calendar Versioning met tags in de vorm `vYYYY.M.D`.
De huidige release staat op de
[releases-pagina](https://github.com/RijksICTGilde/hugo-theme-rijksoverheid/releases).

## Een kwetsbaarheid melden

Dit project volgt het
[Coordinated Vulnerability Disclosure beleid](https://www.ncsc.nl/onderwerpen/coordinated-vulnerability-disclosure)
van het Nationaal Cyber Security Centrum (NCSC). Heb je een
kwetsbaarheid ontdekt, meld die dan verantwoord. Maak geen publiek
GitHub issue aan voor security-bevindingen.

### Voorkeur: melding via NCSC

Stuur je melding aan het NCSC via <cert@ncsc.nl>. Versleutel gevoelige
details met de
[PGP-sleutel van het NCSC](https://www.ncsc.nl/contact/kwetsbaarheid-melden).
Het NCSC coördineert de afhandeling met ons.

### Alternatief: GitHub Security Advisory

1. Ga naar het tabblad **Security** van deze repository.
2. Kies **Report a vulnerability**.
3. Vul het formulier in met omschrijving, reproductie en impact.

## Wat je van ons mag verwachten

* Een ontvangstbevestiging binnen vijf werkdagen.
* Een eerste inhoudelijke reactie binnen tien werkdagen.
* Statusupdates tot de melding is afgehandeld.
* Indien je dat wilt en de melding rechtvaardigt, een vermelding bij
  de fix in de release notes.

## Wat wij van melders vragen

* Geef ons redelijke tijd om de kwetsbaarheid te onderzoeken en op te
  lossen voordat je deze publiceert.
* Voer geen tests uit die productiegegevens of beschikbaarheid kunnen
  schaden.
* Gebruik je bevindingen niet voor andere doelen dan de melding.
